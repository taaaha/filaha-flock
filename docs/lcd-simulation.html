A live simulation of the Filaha Flock box: an emulated character display shows two small status signs and four readings that change over time, with a separate panel for the alerts the box raises.

The box, running

This runs. The screen is an emulated HD44780 controller (the chip on your LCD) fed the same commands the firmware sends: cursor addresses for a 20×4 module, eight custom characters loaded at boot, and only the rows that changed rewritten. The readings drift on their own; use the buttons to make things go wrong.
